## 0. 项目定位（一句话）

汽车之家（autohome）车型**颜色列表 + 各颜色外观图片数量**抓取（流水线 1），以及按 车型+颜色 **下载外观图片**（流水线 2）的工具，Python + requests/bs4/pandas。

## 1. 项目主流程 / 子流程

### 流水线 1：颜色列表 + 外观图片数量

```
输入: spec_id.txt（每行 系列ID_车型ID.Html$spec_id$车型名）
      ↓ read_spec_id_txt()  （utf-8-sig 读取，$ 分三段，非 3 段整行跳过）
      ↓ run_color_list_phase()  阶段一：抓车型页 __NEXT_DATA__ → 提取 colorList/colors/…（并发+令牌桶限速）
      ↓ 生成颜色任务 (url, series_id, spec_id, car_name, color_id, value, color_name, piccount, color_url)
      ↓ process_color_task()    阶段二：抓颜色页 __NEXT_DATA__ callist[claid=1].total → appearance_count
      ↓ 解析失败与"真为 0"区分（失败进 error_tasks.json 重试，不写 CSV）
输出: CSV（utf-8-sig，10 列）; 错误任务 → error_tasks.json（下次运行优先重试）
断点续传: 启动读已有 CSV 的 (spec_id, color_id) 集合，跳过已完成
```

- 涉及文件：`crawler_url_color_exterior_cnt.py`、`spec_id.txt`、`common.py`
- 命令：`python crawler_url_color_exterior_cnt.py`（全量）／`--limit N --rate R`（小样慢速）／`--input/--output/--error-file/--workers/--batch-size`
- 默认并发 20 线程、限速 15 QPS（全局令牌桶，非每线程各自 sleep）

### 流水线 2：按颜色下载外观图片

```
输入: Excel（至少含 color_url, spec_id, name 三列）
      ↓ pandas 读取 → 过滤空 color_url → drop_duplicates(subset=[spec_id, name])
      ↓ process_one_color(): 抓颜色页 __NEXT_DATA__ callist[claid=1].list[:N]
      ↓ 逐张下载 → 魔数校验(JPEG/PNG/WebP) → 存 out_put/<spec_id>_<颜色名>/NN_<原文件名>.jpg
      ↓ "解析成功但无外观图" → 直接标记完成（避免反复重试）
输出: out_put/ 目录树; download_progress.json（checkpoint）; 失败 → download_error_tasks.json
断点续传: checkpoint (spec_id, 颜色名) + 目录文件数≥N 跳过 + 单文件已存在非空跳过
```

- 涉及文件：`crawler_specid_pic_by_color.py`、`spec_id_url_sample_20260715_1.xlsx`（样例）、`common.py`
- 命令：`python crawler_specid_pic_by_color.py` ／`--limit N --workers W --rate R` ／`--retry`（只重试失败）
- 默认 8 线程、8 QPS、每颜色下前 8 张

### 共享底座（common.py）

`TokenBucket` 全局限速（并发锁内结算）｜`get_session()` 线程级 Session 复用｜`load_json_list/save_json_list` 原子写（tmp + os.replace）｜统一请求头

## 3. 关键决策与理由

1. **限速用全局令牌桶而非每 worker sleep**：并发下整体 QPS 可控，不随并发数放大 —— 防站点限流封禁。
2. **"解析失败"与"真为 0"显式区分**（fetch 返回 (count, parsed_ok)）：失败进错误文件重试，0 直接入库 —— 避免污染数据或无限重试。
3. **图片内容魔数校验**：防反爬 HTML/空响应被存成 .jpg。
4. **无外观图的颜色标记完成**：解析成功即确无图，不反复请求。
5. **断点续传三层兜底**（checkpoint / 目录文件数 / 单文件非空）：中断可续。
6. CSV 统一 `utf-8-sig`（带 BOM），Excel 兼容性好；输入 `utf-8-sig` 读取兼容带/不带 BOM。

## 4. 链路快照

1. 输入读取（spec_id.txt / Excel）→ 2. 并发抓页 + 限速（__NEXT_DATA__ 解析）→ 3. 落盘（CSV/图片，原子写 + checkpoint）→ 4. 错误任务回收（error json → 下轮优先）→ 5. 下游合并（魔镜字段拼接，见 Excel 后 8 列）
